1. INSTALLATION & DEPLOYMENT
-----------------------------------------------------------------------------
The deployment configuration has been simplified. You do not need to pass any custom secrets or environment variables. 

Run this single command to deploy the full stack:

helm install subman oci://registry-1.docker.io/idanyossi/subman --version 0.1.0 --namespace subman --create-namespace

-----------------------------------------------------------------------------
2. ACCESSING THE APPLICATION
-----------------------------------------------------------------------------
Wait for the pods to reach the 'Running' state (check with: kubectl get pods -n subman).

Step 1: Get the External IP
   kubectl get svc -n subman

Step 2: Open in Browser
   Navigate to http://<EXTERNAL-IP> (or http://localhost if using Docker Desktop)
