Thank you for installing Subman!

========================================================================
   ACCESSING THE APPLICATION
========================================================================

The frontend is exposed via a LoadBalancer service.

Get the external IP:
  kubectl get svc subman-client -n <namespace>

Open in Minikube:
  minikube service subman-client -n <namespace>

Port-forward (Docker Desktop / kind):
  kubectl port-forward svc/subman-client 8080:80 -n <namespace>
  Then open: http://localhost:8080

========================================================================
   USAGE
========================================================================

No credentials needed. Click Login or Sign Up with any email/password
and you will land on the dashboard immediately.

========================================================================
   CHECKING POD STATUS
========================================================================

  kubectl get pods -n <namespace>

Wait for all three pods to show 1/1 Running:
  - postgres-0
  - subman-api-xxx
  - subman-client-xxx

The API pod runs two init containers before starting:
  1. wait-for-postgres  -- waits until the database is ready
  2. db-migration       -- runs prisma migrate deploy

========================================================================
   CONFIGURATION & DEFAULT VALUES
========================================================================

Default DB password : DefaultPassword123!
Default DB user     : subman_user
Default DB name     : subman_db

Override the DB password:
  helm upgrade --install subman oci://registry-1.docker.io/jsheffer747/subman --version 0.1.0 --set postgres.dbPassword=MyNewPassword

Override multiple values:
  helm upgrade --install subman oci://registry-1.docker.io/jsheffer747/subman --version 0.1.0 --set postgres.dbPassword=MyNewPassword --set postgres.dbUser=myuser --set postgres.dbName=mydb

Use a custom values file:
  helm upgrade --install subman oci://registry-1.docker.io/jsheffer747/subman --version 0.1.0 -f my-values.yaml

========================================================================
   UNINSTALL
========================================================================

Remove the deployment:
  helm uninstall subman -n <namespace>

Remove the deployment AND all database data:
  helm uninstall subman -n <namespace> && kubectl delete pvc -l app=postgres -n <namespace>

NOTE: Reinstalling without deleting the PVC will reuse existing data.
