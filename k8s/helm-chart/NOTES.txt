Thank you for installing Subman!

========================================================================
   1. ACCESSING THE APPLICATION
========================================================================
The frontend is exposed via a LoadBalancer. Run the following command 
to get the External IP:

kubectl get svc subman-client -n {{ .Release.Namespace }}

Once the EXTERNAL-IP is assigned, visit: http://<EXTERNAL-IP>

(Note: If running locally without a LoadBalancer, use port-forwarding):
kubectl port-forward svc/subman-client 8080:80 -n {{ .Release.Namespace }}

========================================================================
   3. ARCHITECTURE NOTES
========================================================================
- Database: StatefulSet with PersistentVolumeClaim.
- Backend: NestJS with an InitContainer for Prisma Migrations.
- Frontend: React behind Nginx acting as a Reverse Proxy to the API.
- Configuration: Hybrid Secret strategy (stringData for DB, data for Base64).
